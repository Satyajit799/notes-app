# 📝 Notes App

A modern and responsive **Notes Application** built using **React** and **Vite**. The application allows users to create, edit, delete, and star notes with automatic data persistence using **Local Storage**. It features a clean user interface enhanced with **Remix Icons** for an intuitive user experience.

---

## 🚀 Features

* 📝 Create new notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* ⭐ Mark notes as favorite
* 💾 Automatic Local Storage support
* 📅 Displays note creation date
* 🎨 Beautiful UI with **Remix Icons**
* ⚡ Fast development with **Vite**
* 📱 Responsive design

---

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript (ES6+)
* CSS3
* Remix Icons
* Local Storage API

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Satyajit799/notes-app.git
```

Move into the project folder

```bash
cd notes-app
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit

```text
http://localhost:5173
```

---

## 💾 Local Storage

This application uses the browser's **Local Storage API**.

* Notes are automatically saved.
* Notes remain available after refreshing the page.
* No backend or database is required.

---

## 📁 Components

### App.jsx

* Main application component
* Manages notes state
* Handles CRUD operations
* Stores notes in Local Storage

### Parent.jsx

* Acts as the parent container for the notes.

### Card.jsx

* Displays individual note cards.
* Provides edit, delete, and favorite actions.

## 🎨 Icons

This project uses **Remix Icons**.

Install using:

```bash
npm install remixicon
```

Import in your project:

```javascript
import "remixicon/fonts/remixicon.css";
```
